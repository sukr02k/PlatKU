1. Executive Summary
KendaraanKu adalah aplikasi mobile Flutter untuk mencatat seluruh aktivitas dan pengeluaran kendaraan pribadi secara offline. Aplikasi ini dirancang sebagai demo program dan bonus source code untuk event SharingSession JagoFlutter.


Highlights:
* Multi-Kendaraan: Kelola motor, mobil, atau kendaraan lain dalam satu aplikasi
* Pencatatan BBM: Catat pengisian bensin lengkap dengan harga, liter, odometer, dan lokasi SPBU
* Pencatatan Servis: Catat riwayat servis, ganti oli, ganti ban, dll dengan foto kwitansi
* Scan Nota/Kwitansi: Ambil foto struk/kwitansi, otomatis tersimpan sebagai lampiran
* Statistik & Grafik: Lihat pengeluaran per kendaraan, konsumsi BBM rata-rata, tren bulanan
* 100% Offline: Semua data tersimpan lokal di device menggunakan SQLite
* Export Data: Export laporan ke PDF atau CSV untuk dokumentasi pribadi


Filosofi Teknis:
Source code ini sengaja dibuat simpel dan straightforward. Tidak menggunakan dependency injection framework, tidak pakai declarative router, tidak pakai abstraksi berlebihan. Tujuannya agar peserta free event bisa langsung baca, paham, dan modifikasi tanpa harus belajar 5 library tambahan dulu. Arsitektur BLoC sederhana (data → presentation) sudah lebih dari cukup untuk aplikasi skala ini.

	3. Arsitektur Aplikasi
3.1 BLoC Architecture (Data → Presentation)
Arsitektur simpel 2 layer tanpa abstraksi berlebihan:


Layer
	Isi
	Contoh
	Data
	Models, Database Helper, Repositories
	VehicleModel, DatabaseHelper, VehicleRepository
	Presentation
	Pages, Widgets, BLoCs
	HomePage, VehicleCard, VehicleBloc
	

Tidak ada domain layer terpisah, tidak ada use case class, tidak ada repository interface/abstract. Repository langsung berisi logic query SQLite dan dipanggil oleh BLoC. Simpel, mudah di-trace, mudah di-debug.

3.3 Alur Data
Alur data sangat linear dan mudah di-trace:


User tap tombol → Page dispatch Event ke BLoC
                  → BLoC panggil Repository method
                  → Repository execute query SQLite via DatabaseHelper
                  → Repository return data (model / List<model>)
                  → BLoC emit State baru
                  → BlocBuilder rebuild UI


Tidak ada abstraksi tambahan. BLoC langsung instantiate Repository, Repository langsung pakai DatabaseHelper.getInstance(). Dependency injection cukup via constructor parameter biasa.

DatabaseHelper Pattern:
class DatabaseHelper {
  static DatabaseHelper? _instance;
  static Database? _database;


  DatabaseHelper._();


  static DatabaseHelper getInstance() {
    _instance ??= DatabaseHelper._();
    return _instance!;
  }


  Future<Database> get database async {
    _database ??= await _initDatabase();
    return _database!;
  }


  Future<Database> _initDatabase() async {
    final path = join(await getDatabasesPath(), 'kendaraanku.db');
    return openDatabase(path, version: 1, onCreate: _onCreate);
  }
}

4. Detail Fitur
4.1 Manajemen Kendaraan
Fitur utama untuk mengelola daftar kendaraan milik user.


Fungsionalitas:
1. Tambah kendaraan baru dengan form lengkap (nama, tipe, merek, model, tahun, plat, warna)
2. Foto kendaraan dari kamera atau galeri
3. Edit informasi kendaraan
4. Arsipkan kendaraan yang sudah dijual (soft delete, data historis tetap ada)
5. Set kendaraan default/utama untuk quick entry
6. Dashboard per kendaraan: ringkasan total pengeluaran, rata-rata konsumsi BBM, servis terakhir


UI/UX:
* Home screen menampilkan card list kendaraan aktif dengan foto thumbnail
* Swipe card untuk aksi cepat (isi BBM, catat servis)
* Tap card untuk masuk ke detail/dashboard kendaraan
* FAB (+) untuk tambah kendaraan baru
* Dropdown filter: Semua / Motor / Mobil
4.2 Pencatatan BBM
Fitur untuk mencatat setiap pengisian bahan bakar.


Fungsionalitas:
1. Form input: tanggal, odometer, liter, harga/liter, jenis BBM, nama SPBU
2. Auto-calculate total biaya dari liter × harga
3. Toggle full tank / partial fill (mempengaruhi perhitungan konsumsi)
4. Scan/foto struk SPBU — tersimpan sebagai lampiran
5. Kalkulasi otomatis: km/liter, biaya/km sejak pengisian terakhir
6. Riwayat pengisian dengan ListView dan filter tanggal


Logika Konsumsi BBM:
Perhitungan konsumsi menggunakan metode full-tank-to-full-tank:
* Konsumsi = (Odometer sekarang − Odometer pengisian full tank sebelumnya) / Liter sekarang
* Jika pengisian partial, data dikumpulkan sampai pengisian full tank berikutnya
* Rata-rata konsumsi dihitung dari semua record full-tank yang valid
4.3 Pencatatan Servis
Fitur untuk mencatat semua aktivitas servis dan perawatan kendaraan.


Kategori Servis (Default):
* Ganti Oli Mesin
* Ganti Oli Gardan (motor matic)
* Ganti Ban
* Tune Up / Servis Rutin
* Ganti Aki
* Ganti Kampas Rem
* Ganti V-Belt (motor matic)
* Servis AC (mobil)
* Perpanjang STNK / Pajak Kendaraan
* Lain-lain (custom input)


Fungsionalitas:
1. Form input: tanggal, kategori, deskripsi, biaya, nama bengkel, odometer
2. Scan/foto kwitansi bengkel — tersimpan sebagai lampiran
3. Set reminder: next service di odometer X atau tanggal Y
4. Riwayat servis per kendaraan dengan filter kategori
5. User bisa tambah kategori servis custom
4.4 Scan Nota / Kwitansi
Fitur capture foto struk/kwitansi yang terintegrasi dengan pencatatan BBM dan servis. Bukan OCR — murni foto lampiran.


Alur Kerja:
1. Saat input BBM atau servis, tap tombol kamera
2. Pilih: Ambil Foto (kamera) atau Pilih dari Galeri
3. Preview foto sebelum simpan
4. Foto di-compress (max 1280px, quality 80%) lalu disimpan ke app directory
5. Nama file terstruktur: {vehicle_id}_{type}_{timestamp}.jpg
6. Foto bisa dilihat kembali dari detail record BBM/servis (tap untuk fullscreen)
7. Galeri semua nota per kendaraan (GridView)

5. BLoC State Management
Setiap fitur utama memiliki BLoC sendiri. Pattern konsisten: Event masuk, BLoC proses via Repository, emit State baru.


BLoC
	State (Freezed)
	Events
	VehicleBloc
	initial, loading, loaded, error
	LoadVehicles, AddVehicle, UpdateVehicle, ArchiveVehicle, SetDefault
	FuelLogBloc
	initial, loading, loaded, error
	LoadFuelLogs, AddFuelLog, UpdateFuelLog, DeleteFuelLog, FilterByDate
	ServiceLogBloc
	initial, loading, loaded, error
	LoadServiceLogs, AddServiceLog, UpdateServiceLog, DeleteServiceLog, FilterByCategory
	DashboardBloc
	initial, loading, loaded, error
	LoadDashboard, ChangePeriod, ChangeVehicle
	ImageBloc
	initial, picking, picked, error
	CaptureImage, PickFromGallery, DeleteImage
	SettingsBloc
	SettingsState (single state)
	LoadSettings, UpdateTheme, UpdateCurrency, UpdateUnit
	

Contoh Lengkap — FuelLogBloc:
// === Event (Freezed) ===
@freezed
class FuelLogEvent with _$FuelLogEvent {
  const factory FuelLogEvent.load(int vehicleId) = _Load;
  const factory FuelLogEvent.add(FuelLogModel fuelLog) = _Add;
  const factory FuelLogEvent.delete(int id) = _Delete;
  const factory FuelLogEvent.filterByDate(DateTime start, DateTime end) = _Filter;
}


// === State (Freezed) ===
@freezed
class FuelLogState with _$FuelLogState {
  const factory FuelLogState.initial() = _Initial;
  const factory FuelLogState.loading() = _Loading;
  const factory FuelLogState.loaded(
    List<FuelLogModel> logs,
    FuelStats stats,
  ) = _Loaded;
  const factory FuelLogState.error(String message) = _Error;
}


// === BLoC ===
class FuelLogBloc extends Bloc<FuelLogEvent, FuelLogState> {
  final FuelLogRepository _repository;  // inject via constructor


  FuelLogBloc(this._repository) : super(const FuelLogState.initial()) {
    on<_Load>(_onLoad);
    on<_Add>(_onAdd);
    on<_Delete>(_onDelete);
  }


  Future<void> _onLoad(_Load event, Emitter<FuelLogState> emit) async {
    emit(const FuelLogState.loading());
    final result = await _repository.getByVehicle(event.vehicleId);
    result.fold(
      (failure) => emit(FuelLogState.error(failure.message)),
      (logs) {
        final stats = _calculateStats(logs);
        emit(FuelLogState.loaded(logs, stats));
      },
    );
  }
}

7. Scope & Batasan untuk Free Event
Termasuk (In Scope):
* CRUD lengkap untuk kendaraan, BBM, dan servis
* Foto nota/kwitansi (camera + gallery, compressed)
* Dashboard dengan grafik dasar (fl_chart)
* Export PDF dan CSV
* Backup/restore database SQLite
* Light & Dark theme via SharedPreferences
* BLoC + Freezed + Dartz pattern yang rapi sebagai pembelajaran
* Navigator v1 sederhana tanpa routing library


Tidak Termasuk (Out of Scope):
* OCR / text recognition dari foto nota
* Cloud sync / multi-device (butuh backend)
* GPS tracking perjalanan
* Push notification untuk reminder servis
* Multi-bahasa (cukup Bahasa Indonesia)
* Integrasi API harga BBM real-time
* Social features (share, compare antar user)


Potensi Upgrade (Upsell Materi Berbayar):
* OCR scan nota dengan Google ML Kit
* Cloud sync dengan Firebase / Supabase
* GPS trip logging & route recording
* Local notification reminder servis
* Multi-language support
* Monetisasi: Google Ads integration
* Migration ke Clean Architecture full layer (untuk yang mau scale up)
